# arcanum.garden

Website of Arcanum (listed in the App Store as Arcanum Garden), a life diary app: an archetype test, short daily entries, and a book about you that grows every week.

Static Next.js site, exported to `./out` and deployed to GitHub Pages from the `main` branch.

## Development

    npm ci
    npm run dev      # local preview
    npm run build    # static export to ./out

Legal texts in `content/legal/` are copied from the app and must stay word for word.
